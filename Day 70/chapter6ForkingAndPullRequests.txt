Forking & Pull Requests (Nutshell)
What is a Fork?

A fork is your own copy of someone else's GitHub repository.

You use a fork when you don't have write access to the original repository but want to contribute.

        │ Fork
        ▼

Command Line Process
1. Fork the repository

Do this on GitHub by clicking Fork.

2. Clone your fork
git clone https://github.com/your-username/project.git
3. Enter the project
cd project
4. Create a feature branch
git switch -c fix-navbar
5. Make changes

Edit the code.

6. Stage changes
git add .
7. Commit
git commit -m "Fix navbar alignment"
8. Push to your fork
git push -u origin fix-navbar
9. Create a Pull Request

On GitHub:

Open your fork.
Click Compare & pull request.
Add a title and description.
Submit the Pull Request.
What is a Pull Request (PR)?

A Pull Request is a request asking the owner of the original repository to pull (merge) your changes into their project.

It is not a Git command—it's a GitHub feature.

Your Fork
     │
     │ Pull Request
     ▼
Original Repository

The repository owner can:

✅ Approve
💬 Request changes
❌ Reject
🔀 Merge
